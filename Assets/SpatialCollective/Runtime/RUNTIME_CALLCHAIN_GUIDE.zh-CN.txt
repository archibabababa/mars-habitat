【SpatialCollective Runtime 调用链时序说明（独立版）】

说明：
- 本文件用于按“调用链”理解 Runtime 代码执行顺序。


==================================================
1) 启动链路（Start -> 首个房间）
==================================================
Unity 生命周期
-> CollectiveExperience.Start()  // 启动总控入口：组装运行时依赖、创建指针与过渡资源。
-> 校验 rig/inputReader/stateController/study/linkedViews/head/trackingOrigin  // 任一缺失都会抛异常并终止启动。
-> profile = stateController.Profile  // 从 InteractionProfile 读取交互阈值与布局比例。
-> CreateMenu() // 创建世界空间面板根节点与 Dashboard。
-> RefreshMenuBindings() // 把 JSON 命令映射写回按钮组件。
-> linkedViews.Initialize()// 创建总览/详情离屏相机与 RenderTexture。
-> dashboard.Initialize() // 初始化仪表盘状态和演练可视化对象。
-> roomScale.Initialize(this) // 建立 room-scale 提示圈并订阅 tracking origin 变化。
-> （条件）dashboard.ConfigureHeadsetLayout() // 头显/Android 启用只读三视图工作区。
-> CreateFade() + 创建 reticle/pointerLine // 准备视图切换黑幕与手/柄指针。
-> stateController.Commit() // 把当前初始状态记为 committed。
-> PlaceOverview() + PlaceMenu() // 先把总览与面板摆到用户前方。
-> rig.Rebuild() // 首次把参数变换结果写入运行时网格。
-> StartCoroutine(BeginExperience()) // 异步进入参考舱。
-> ChangeView(true, referenceRoom)（对应 CollectiveExperience.ChangeView） // 淡出->重定位->淡入。
-> roomScale.Calibrate() // 过渡后首个稳定位姿作为 room-scale 参考中心。

结果：完成初始场景定位并进入可交互状态。

==================================================
2) 每帧输入总线（Update）
==================================================
Unity.Update()
-> CollectiveExperience.Update()  // 每帧总线入口：读输入、分发交互、限频刷新文本。
-> KeyboardInput() // 处理键盘命令与桌面 WASD/鼠标视角。
-> frame = inputReader.Read()	// 生成统一输入帧 CollectiveInputFrame。
-> 组装 ray  // 优先 frame.pointer；无指针则退回 head.forward，鼠标模式转屏幕射线。
-> ProcessInput(frame, ray)	 // 主交互分发：工程模式或空间模式。
-> （每 0.08 秒）RefreshStatus()	 // 降低 UI 刷新频率避免抖动。

inputReader.Read() 输入来源优先级：
XR Hands
-> Meta Aim 射线（可用时） // 首选：手部追踪+有效 aim flags。
-> OpenXR HandInteraction 射线（备选） // Meta Aim 不可用时，尝试 EXT_hand_interaction 指针。
-> XR Controller（降级） // 无手部追踪时读取右/左手柄按键与姿态。
-> Mouse（桌面降级） // 无 XR 活跃设备时，鼠标左键作为 primary。

==================================================
3) 工程面板单手编辑链路,捏合-拖动-释放（Pinch-Drag-Release）
==================================================
ProcessInput()
-> gesture.Step(frame)（对应 CollectiveGestureSession.Step） // 计算 Began/Held/Released/Interrupted。
-> Physics.Raycast(layer=9) (UI的层级) // 只打 UI 层，命中按钮/参数/总览屏。
-> 若 gesture.Began 且命中参数/节点 // 进入编辑准备分支。
-> dragStartHeight + dragStartValue（记录起点） // 用于后续线性映射 value。
-> dragging = true（开始单手拖动）
-> dragging && gesture.Held // 持续计算拖动增量。
-> value = dragStartValue + delta/handTravel*range // 手高差映射到参数区间。
-> activeControl.Write(...) 或 rig.SetBaseline(...) // 写控件参数或区域基准值。
-> rig.MarkDirty() // 仅标脏(就是数据改了)，不立即每帧重建。
-> dragging && gesture.Released // 释放时结束拖动。
-> rig.Rebuild() // 视觉上固定本次预览结果。
-> 等待 Apply / Undo / Compare // Apply 才会 Commit，Undo 回 committed。

提交点：只有 Execute(Apply) 才会 stateController.Commit()。

==================================================
4) 双手编辑链路,双手动跨度（Bimanual Span）
==================================================
ProcessInput()
-> bimanual.Step(frame, handTravel)	 // 更新双手状态与 Delta。
-> bimanual.Began // 双手首次同时按下。
-> 校验 bimanualSelected / comparing / transitioning // 无目标或比较态/过渡态则拒绝进入。
-> 记录 bimanualStartValue // 保存编辑起点。
-> bimanual.Active // 双手保持阶段。
-> value = start + Delta * range // 双手间距变化映射到参数变化。
-> selectedControl.Write//写参数, 控件目标优先，否则改当前 selectedRegion。
-> rig.MarkDirty() // 标脏(修改了数据)等待统一重建。
-> bimanual.Ended // 双手释放结束。
-> rig.Rebuild() // 冻结预览。
-> 进入 bimanualRecovery（要求先松手） // 防止连击触发下一次编辑。

==================================================
5) 直接空间手势链路（ProcessSpatialInput）
==================================================
ProcessInput()
-> 条件满足（directSpatialInteraction + Hand/HandGaze/None） // 空间模式入口门控。
-> ProcessSpatialInput(frame, ray, dt) // 进入空间手势状态机。

ProcessSpatialInput 主要阶段：
1. 跟踪可用性校验
   - 不可用：CancelSpatialEdit() + 提示恢复 // 回滚未提交编辑，等待追踪恢复。
2. spatialNeedsRelease 门控
   - 必须先张手后再接收新手势 // 防止恢复瞬间把旧捏合误判为新命令。
3. Idle 手势入口
   - 双手 pinch -> Span // 双手间距调形状( shape)。
   - 右手单 pinch -> PendingRight -> Shape/Travel // 短暂等待第二只手，不到场则转单手编辑。
   - 左中指 pinch -> PendingLeft -> Coupling // 调整联动权重。
4. 编辑写值
   - Shape: rig.SetBaseline(region, value) // 普通区域/独立舱形变。
   - Travel: rig.SetTravel(detachedIndex, value) // 独立舱路径进度。
   - Coupling: rig.SetCoupling(...) // 核心或分支联动系数。
5. 释放提交
   - FinishSpatialEdit() // 对比起始快照，判断是否发生变化。
   - 有变化则 Commit + 写入 spatialHistory // 形成可回退历史（上限 20）。

特殊手势：
- 右中指 hold：JumpToCabin(node) // 长按直接跳转目标舱。
- 双中指 hold：Execute(ToggleView) // 进入/退出舱内视图。
- 左拳 hold：从 spatialHistory 回退 // 恢复上一条空间手势提交结果。

6) 命令执行链路（按钮/键盘共用）
==================================================
CollectiveButton 点击 或 键盘映射
-> CollectiveExperience.Execute(command, arg) // 命令统一收口点。
-> InteractionProfile.ValidateCommand(...) // 防止非法命令参数污染状态。
-> switch(command) // 根据命令分支执行业务。

典型分支：
- Apply
  -> StopMotion()  //开始编辑前停止演示、自动飞行
  -> rig.Rebuild()//根据当前姿态变换顶点、更新批次可见性和包围盒，并通知监听者。
  -> stateController.Commit()//将当前预览作为已应用状态；比较中先返回预览
- Undo
  -> StopMotion()
  -> stateController.Undo()
- ToggleCompare
  -> BeginCompare()/EndCompare()
- ToggleView
  -> StartCoroutine(ChangeView(...))
- ToggleDemo/RestartDemo
  -> study.Toggle()/Seek(0)

注释：
- Apply：把“预览态”升级为 committed（可存盘、可比较基准）。
- Undo：恢复 committed，不是多步历史撤销。
- ToggleCompare：切换“显示 committed”与“显示 proposal”。
- ToggleView：触发 ChangeView 协程完成淡入淡出切换。

7) 几何计算链路（参数 -> 顶点）（CollectiveRig.cs）
==================================================
SetBaseline / SetCoupling / SetTravel
-> rig.MarkDirty() // 写值后只标记“待重建”。
-> CollectiveRig.Update()（CollectiveRig.cs，按 deformationUpdatesPerSecond 节流） // 定时统一处理 dirty。
-> EvaluateActivation()计算 Actual[6] // 联动开关影响 1..3 区。
-> Rebuild() // 几何重建收口。
-> EvaluatePose() // 先算 driver 矩阵。
-> CollectiveKinematics.Evaluate(...)（CollectiveData.cs） // 分层父子驱动运动学。
-> 叠加 S08/O13 路径位姿 // 二次贝塞尔平移 + 自转。
-> 顶点批处理变换写回 mesh.vertices // basis -> buffer -> mesh。
-> mesh.RecalculateBounds() // 更新包围盒供裁剪使用。
-> GeometryChanged?.Invoke() // 通知依赖方几何已更新。

8) 联动视图渲染链路,概览+房间（Overview + Room）CollectiveLinkedViews.cs
==================================================
CollectiveLinkedViews.LateUpdate()
-> 达到 refreshRate 周期 // 节流避免每帧都离屏渲染。
-> RenderNow() // 双相机渲染总入口。
-> UpdateViewState() // 先更新相机状态再渲染。
-> 更新 OverviewCamera // 总览固定画幅，跟随模型位姿。
-> 更新轨迹线 SampleFlight（脚本: Assets/SpatialCollective/Runtime/CollectiveRig.cs） // S08/O13 路线采样为 33 点。
-> 计算 RoomCamera // 根据当前 inspection 节点生成详情视图。
   - 普通舱：1:1 身体位移映射
   - 独立舱：PositionDetached()（）
-> OverviewCamera.Render()
-> RoomCamera.Render()   
-> dashboard.Refresh()（CollectiveDashboard.cs） // 把最新纹理与状态同步到 UI。

9) 视图切换链路（overview <-> inside）CollectiveExperience.cs
==================================================
Execute(ToggleView)   //空间双中指 
-> StartCoroutine(ChangeView(inside, node)) // 进入协程，避免阻塞主线程。
-> 淡出（fadeMaterial alpha 0->1） // 过渡期间屏蔽视觉突变。
-> 更新 rig.inside/selectedNode/selectedRegion // 切换目标上下文。
-> inside：计算 roomRotation/roomAnchor 并摆放 rig // 把舱内地板对齐到用户位置。
-> overview：PlaceOverview() // 恢复缩略整体模型位置。
-> rig.Rebuild()(CollectiveRig.cs） + PlaceMenu()（CollectiveExperience.cs） + linkedViews.Calibrate()（CollectiveLinkedViews.cs） // 几何、面板、相机参考一次性同步。
-> 淡入（alpha 1->0） // 释放过渡锁，恢复交互。

10) 状态管理链路（预览/应用/对比/持久化）
==================================================
- 预览：参数写 rig（CollectiveRig.cs），但未 Commit
- 应用：Execute(Apply)（CollectiveExperience.cs） -> Commit()（CollectiveStateController.cs）
- 撤销：Execute(Undo)（CollectiveExperience.cs） -> Undo()（CollectiveStateController.cs） -> Restore(committed)（同脚本）
- 对比：BeginCompare()（CollectiveStateController.cs）保存 proposal 并显示 committed；EndCompare()（同脚本）恢复 proposal
- 存盘：SaveApplied()（CollectiveStateController.cs）保存 committed
- 读盘：LoadPreview()（CollectiveStateController.cs）读取快照并 Restore

中文注释：
- 预览：所有拖动/手势先改 rig 当前值，属于“未确认状态”。
- 应用：Commit 后，当前预览成为“新的已应用基线”。
- 撤销：Undo 始终回到 committed，不回滚到任意中间步骤。
- 对比：BeginCompare 进入“看已应用”模式；EndCompare 回到进入前 proposal。
- 存盘：只落盘 committed（不是当前所有预览）。
- 读盘：LoadPreview 读取后仍是预览，仍需 Apply 才正式生效。

11) 对照阅读建议（断点顺序）
==================================================
1. 在 CollectiveExperience.Update() 下断点，确认输入总线。
2. 做一次单手编辑，跟：gesture.Began -> Held -> Write -> MarkDirty。
3. 跳到 CollectiveRig.Update()，看 dirty 触发 Rebuild。
4. 在 EvaluatePose() 看 Matrices 更新。
5. 在 CollectiveLinkedViews.RenderNow() 看双相机渲染时机。
6. 触发 Apply/Undo/Compare，观察 stateController：
   - Commit()
   - Undo()
   - BeginCompare()/EndCompare()

输入 -> 参数 -> 几何 -> 视图 -> 状态”
